# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/abelmatos/meeting-reminder/security/advisories/new),
not in a public issue.

Include what you found, how to reproduce it and which version you used. You
should get a first answer within a week. This is a personal project, so there
is no bug bounty.
